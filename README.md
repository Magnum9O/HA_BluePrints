<h1>Home Assistant Blueprints And Packages</h1>
<p>This repo collects reusable Home Assistant blueprints, packages, scripts, and examples extracted from real setups and cleaned up for sharing.</p>
<ul>
  <li>Blueprints for device-specific automations</li>
  <li>Packages for multi-file logic and reusable workflows</li>
  <li>Helpers, examples, and public setup notes</li>
</ul>
<p>
  Current shared packages include the public <code>packages/energy</code> package for overload alerts and automatic load shedding.
</p>
<p>
  In simple terms: create the labels, assign them, copy the package, restart Home Assistant, and you already have the core monitoring and shedding flow.
</p>
<p>
  For the detailed setup, examples, and optional Python threshold sync, check each package or blueprint README and related Home Assistant Community posts.
</p>
